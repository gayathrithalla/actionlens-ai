👁️ ActionLens AI

Turn anything you see into something you can act on.

ActionLens AI is a Gemini-powered multimodal vision chatbot that analyzes images and converts visual information into clear, actionable next steps.

Instead of simply describing what's inside an image, ActionLens answers:

"What is this, and what should I do next?"

🚀 Features

- 📷 **Image Analysis** — Upload notices, documents, receipts, study materials, posters, forms, screenshots, and more.
- 🧠 **Gemini Vision AI** — Understands and extracts meaningful information from images.
- 🎯 **Actionable Insights** — Converts visual information into practical actions.
- 📅 **Important Dates** — Identifies deadlines and time-sensitive information.
- 📋 **Requirements & Eligibility** — Extracts requirements, conditions, and eligibility criteria.
- ⚠️ **Warnings** — Highlights missing or unclear information.
- 💬 **AI Chat** — Ask follow-up questions about the uploaded image.
- 📱 **WhatsApp Integration** — Send the generated analysis directly to WhatsApp using Twilio.
- 🔒 **No Model Training Required** — Uses Gemini's multimodal capabilities directly.
